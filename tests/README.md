# tests/

Katalog `tests/` zawiera lekkie testy i checklisty manualne dla mechanik Haiku Cosmos.

Zasady:
- testy/checklisty powinny być małe i skupione na jednej mechanice,
- każdy plik powinien jasno wskazywać przypadki wejściowe i oczekiwane zachowanie,
- bez potrzeby nie dodajemy ciężkiej infrastruktury testowej.

HAIKU COSMOS — ROBOCZY DOKUMENT JĘZYKA HAIKU KART

Status:
ROBOCZY / KIERUNEK TEKSTOWY

Obszar:
haiku kart, opis kart, język poetycko-mechaniczny, SUB-META, karty R1–R4

Cel dokumentu:
Ustalić spójny język haiku dla kart Haiku Cosmos, zanim powstaną finalne teksty kart.

Ten dokument nie zawiera jeszcze finalnych haiku.
Ten dokument definiuje bazę słów, obrazów, napięć i zasad składania haiku.

Najważniejsza zasada:
Haiku nie ma tłumaczyć mechaniki dosłownie.
Haiku ma sprawić, że gracz poczuje mechanikę przez obraz, cięcie i ruch.

1. ZAŁOŻENIE GŁÓWNE

Haiku karty jest krótkim śladem działania karty.

Nie jest:

* instrukcją,
* opisem statystyk,
* tutorialem,
* tooltipem technicznym,
* nazwą efektu.

Jest:

* obrazem koloru,
* cieniem funkcji,
* małym rytuałem odczytu karty,
* pomostem między mechaniką a kosmologią gry.

Każda karta powinna mieć haiku, które działa na trzech poziomach:

1. Obraz
   Gracz widzi coś nieruchomego: kamień, pył, rdzeń, taflę, nić, pęknięcie, pierścień.

2. Cięcie
   W środku tekstu pojawia się zatrzymanie, próg, zmiana napięcia albo pauza.

3. Ruch
   Ostatni obraz zaczyna działać: zapala, wiąże, płynie, chłodzi, obraca, stabilizuje, rozprasza.

Model:
obraz statyczny -> cięcie / próg -> ruch / funkcja

2. DLACZEGO NIE TRZYMAMY SIĘ SZTYWNO 5-7-5

Nie trzymamy się sztywno sylab 5-7-5, ponieważ:

* język polski szybko robi się ciężki przy mechanicznym liczeniu sylab,
* tekst może stać się płaski,
* ważniejsza jest funkcja cięcia i oddechu,
* haiku ma mieścić się w UI i być czytelne,
* karty muszą mieć własny język, nie szkolną formę wiersza.

Zasada praktyczna:
Haiku powinno mieć 3 wersy.
Każdy wers powinien być krótki.
Całość powinna dać się przeczytać jednym spokojnym oddechem.

Nie wymagamy 5-7-5.
Wymagamy:

* obrazu,
* cięcia,
* ruchu.

3. OGÓLNA STRUKTURA HAIKU

Wers 1:
obraz statyczny

Wers 2:
cięcie, próg, pauza, napięcie, zmiana perspektywy

Wers 3:
ruch, przemiana, funkcja karty

Przykład strukturalny, bez finalnego tekstu:
[obiekt / materiał / kolor]
[granica / cisza / pęknięcie]
[działanie / przepływ / przemiana]

Dobre kierunki:
kamień czeka
pęknięcie otwiera ciszę
krąg zaczyna płynąć

Złe kierunki:
zwiększa zasięg
daje bonus do szybkości
aktywuje efekt czerwony

Mechanikę zamieniamy na obraz.

zwiększa zasięg -> krąg się rozszerza
spowalnia obiekty -> ruch zastyga
wiąże dwa sloty -> nić domyka most
stabilizuje konfigurację -> rdzeń oddycha równo
resetuje napięcie -> pęknięcie zarasta

4. RZĘDY KART JAKO TON HAIKU

R1 — WEJŚCIE

Sens:
pierwszy gest, fundament, czysty kolor, aktywacja, impuls.

Ton:
prosty, pierwotny, czynny.

Haiku R1 powinno być najbliżej koloru.
Nie powinno jeszcze mówić o skomplikowanej relacji.
To kolor w pierwszym działaniu.

Model R1:
obraz koloru
próg / pierwsze pęknięcie
kolor zaczyna działać

Słowa rzędu:
wejście, próg, iskra, pierwszy oddech, ślad, znak, otwarcie, początek, kierunek

Unikać:
zbyt wielkiej kosmologii.
R1 nie jest jeszcze jednością świata.

R2 — USTABILIZOWANIE

Sens:
dwa kolory, relacja, wiązanie, most, synchronizacja.

Ton:
relacyjny, napięty, alchemiczny.

Haiku R2 nie powinno być sumą dwóch R1.
Powinno opisać to, co powstaje pomiędzy kolorami.

Model R2:
dwa obrazy stoją naprzeciw
pojawia się nić / most / napięcie
układ zaczyna działać razem

Słowa rzędu:
wiązanie, splot, most, nić, spoiwo, wymiana, dotyk, granica, równowaga, takt

Unikać:
dosłownego wymieniania kolorów.
Nie pisać “czerwony i żółty”.
Lepiej: “żar” i “złota nić”.

R3 — UCISZENIE

Sens:
trzy kolory, stabilizacja, układ, głębszy rytm, opanowanie napięcia.

Ton:
rytualny, spokojniejszy, bardziej świadomy.

Haiku R3 powinno brzmieć jak układ, który nauczył się oddychać.
To nie jest już zwykła relacja dwóch sił.
To pierwszy większy porządek.

Model R3:
trzy znaki / trzy kamienie / trzy obroty
cisza porządkuje napięcie
układ zaczyna płynąć jednym rytmem

Słowa rzędu:
trójznak, układ, rytm, uspokojenie, równy oddech, stabilizacja, próg ciszy, potrójny krąg, trzecia nić

Unikać:
zbyt gwałtownych czasowników.
R3 nie powinno wybuchać.
R3 powinno uciszać.

R4 — JEDNOŚĆ

Sens:
cztery kolory, pełny układ, kosmologia, integracja, globalna konfiguracja.

Ton:
wysoki, spokojny, prawie sakralny.

Haiku R4 powinno być najprostsze i największe jednocześnie.
Nie powinno opisywać pojedynczej funkcji.
Powinno mówić o tym, że cały system staje się jednym ruchem.

Model R4:
cały układ nieruchomieje
granice kolorów cichną
wszystko rusza jednym oddechem

Słowa rzędu:
jedność, pełny krąg, cztery strony, rdzeń, eon, całość, wspólny oddech, zamknięty obieg, kosmos, centrum

Unikać:
nadmiaru patosu.
R4 ma być wielkie, ale nie napuszone.

5. TIERY DR / sDR / pDR

Na tym etapie nie tworzymy osobnych haiku dla DR, sDR i pDR.

Powód:
Tier zmienia moc, trwałość i wartość karty.
Haiku opisuje archetyp karty, nie jej poziom liczbowy.

Proponowany model:
jedno haiku na ID karty
tier zmienia podpis, oprawę albo rangę tekstową

Robocze epitety tierów:

DR:
ślad, ziarno, pierwszy znak, forma prosta, odcisk

sDR:
rezonans, splot, pogłębienie, drugi obieg, utrwalony znak

pDR:
pieczęć, korona, rdzeń, pełny znak, forma przebudzona

Przykład modelu nazewniczego:
DR — Ślad Żaru
sDR — Rezonans Żaru
pDR — Pieczęć Żaru

Haiku pozostaje wspólne.

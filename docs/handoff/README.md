# docs/handoff

Handoff to krótki dokument przekazania stanu po większej zmianie.

## Zasady

- Handoff nie zastępuje dokumentacji kanonicznej (`docs/current/`).
- Ma pomagać szybko wrócić do projektu po przerwie.
- Powinien zawierać:
  - aktualny stan,
  - ostatnie decyzje,
  - znane problemy,
  - rekomendowany następny krok.

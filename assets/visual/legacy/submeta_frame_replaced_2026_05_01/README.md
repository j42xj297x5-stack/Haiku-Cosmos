# SUB-META Frame Legacy Evidence - 2026-05-01

This directory preserves the previous active SUB-META astrolabe root frame parts that were replaced by `submeta_main_frame_v01`.

The old set used:

- 4 corner SVGs,
- 4 full edge SVGs,
- 2 center ornament SVGs,
- `modular_frame_kit_v01_manifest.json` as the shared visual-kit manifest.

It was replaced because the accepted main frame model is segmented: 4 corners, 4 center ornaments, and 8 connector segments. The new active runtime candidate is documented in:

- `assets/visual/submeta/submeta_main_frame_v01_manifest.json`
- `assets/visual/submeta/svg/main_frame_v01/`

These files are evidence/history only. They are not the active SUB-META root frame source for the new segmented runtime path.

The original shared `modular_frame_kit_v01` files remain in place because that kit also contains HUD, card, separator, slot, and preview assets that are not replaced by this pass.

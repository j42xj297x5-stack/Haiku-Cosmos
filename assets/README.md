# assets

> Status: STRUKTURA ROBOCZA
> Obszar: assety projektu

Ten katalog przechowuje przygotowywane assety projektu.

Na tym etapie dodana jest tylko struktura pod bibliotekę wizualną SUB-META, HUD i elementy współdzielone.

## Co tu trafia

- eksportowane później assety SVG z Figmy,
- placeholdery robocze, jeśli są opisane w pipeline,
- pliki współdzielone między SUB-META i HUD.

## Czego tu nie wrzucać

- finalnych grafik bez osobnego asset pass,
- rastrów PNG/WebP w ścieżkach SVG,
- fontów,
- cudzych lub skopiowanych grafik,
- plików runtime i importów builda.

Finalne grafiki nie są jeszcze dodane.
